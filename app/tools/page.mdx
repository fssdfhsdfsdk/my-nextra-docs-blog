在 LeetCode 上，广度优先搜索（BFS）和狄克斯特拉算法（Dijkstra）是解决图论与最短路径问题的重要工具。以下是两类算法的核心特点、经典题目推荐、代码模板及解题技巧，帮助你系统掌握并高效刷题。


## 一、算法对比

| 特性         | BFS                          | Dijkstra                         |
|--------------|------------------------------|----------------------------------|
| 适用图类型   | 无权图                        | 有权图（非负权重）               |
| 最短路径保证 | 是（边数最少）                | 是（权重和最小）                 |
| 数据结构     | 普通队列                      | 优先队列（最小堆）               |
| 时间复杂度   | O(V + E)                      | O((V + E) log V)                 |
| 核心思想     | 层序遍历                      | 贪心 + 松弛操作                  |

📌 BFS 模板（Python）：
```python
from collections import deque

def bfs(start, graph):
    queue = deque([start])
    visited = {start}
    while queue:
        node = queue.popleft()
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
```

📌 Dijkstra 模板（Python）：
```python
import heapq

def dijkstra(start, graph, n):
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

## 四、解题技巧与注意事项

### ✅ BFS 技巧
- 使用 `visited` 集合避免重复访问
- 多源 BFS：将多个起点同时入队（如 542、994）
- 层序计数：记录 `level` 或 `step` 表示步数
- 网格题常用方向数组：
  ```python
  directions = [(0,1), (1,0), (0,-1), (-1,0)]
  ```

### ✅ Dijkstra 技巧
- 使用 `heapq` 实现最小堆
- 松弛条件：`if new_dist < dist[v]`
- 可结合 `visited` 剪枝优化
- 变种题注意状态扩展（如中转次数、概率乘法等）

### ⚠️ 常见错误
- BFS 忘记标记 visited，导致死循环
- Dijkstra 未判断 `d > dist[u]`，导致重复处理
- 网格题越界未检查
- 优先队列中存储状态不完整（如缺少步数、中转次数等）
